# Tour de contrôle CEP

Consolidation des comptes d'exploitation projet (CEP V11-20) : CA, marge et activité du portefeuille.

- **Lancer sur un PC Windows** : double-cliquer sur [`start.bat`](start.bat). Node.js, les mises à jour de l'application, les dépendances et la compilation sont gérés automatiquement ; les données déjà scannées sont conservées.
- **Documentation complète** : [`app/README.md`](app/README.md).
- Le modèle de CEP V11-20 vierge n'est pas inclus dans ce dépôt public (document interne).
